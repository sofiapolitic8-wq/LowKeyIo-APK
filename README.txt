LowKey.io APK project (v9.72)
1) Upload this whole folder to a new GitHub repo (keep the .github folder).
2) Open the repo > Actions > "Build LowKey.io APK" > wait ~5-10 min.
3) Open the finished run > Artifacts > LowKey.io-APK > download, unzip, install the .apk.
Local build: install Android Studio, open this folder, Build > Build APK(s).
